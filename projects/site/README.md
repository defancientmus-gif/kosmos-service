# Сайт КОсмос сервис

Первый MVP личного сайта сервиса.

## Как открыть

Открыть файл:

`projects/site/index.html`

Backend пока не подключён. Форма работает локально: собирает данные и формирует текст заявки, который можно скопировать в Telegram/WhatsApp/CRM.

## Что уже есть

- Первый экран с быстрым выбором сценария: ремонт, предзаказ техники, корпоративная заявка.
- Блок услуг.
- Блок процесса ремонта.
- Блок юридических ограничителей.
- Ссылка на Яндекс.Карты.
- Hero-изображение: `assets/hero-repair.png`.

## Что подключить дальше

- Реальный телефон, Telegram, WhatsApp.
- Telegram-бот или CRM endpoint для заявок.
- Реквизиты ИП и проверенные юридические тексты.
- Страницу прайса.
- Каталог новой/б/у техники и сценарий предзаказа.
