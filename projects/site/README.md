# Сайт Космос Сервис

Первый MVP личного сайта сервиса.

## Как открыть

Открыть файл:

`projects/site/index.html`

Backend пока не подключён. Форма работает локально: собирает данные и формирует текст заявки, который можно скопировать в Telegram/WhatsApp/CRM.

## Что уже есть

- Полноэкранный видео-герой с реальным рабочим местом сервиса.
- Форма, которая собирает понятный текст заявки: ремонт, подбор техники, цифровая помощь, бизнес-задача.
- Блок лаборатории с реальными фото мастерской.
- Блок фирменного стиля с актуальным логотипом, wordmark KOSMOS и визитками.
- Блок принципа “меньше шума”: клиенту нужен следующий шаг, а не сайт-лабиринт.
- Блок приложения `Разберёмся`: AI-агент, умные заметки, голосовая помощь.
- Блок юридических ограничителей.
- Ссылка на Яндекс.Карты.
- Ассеты: `assets/real/`, `assets/brand/`, `assets/razberemsia/`.

## Что подключить дальше

- Реальный телефон, Telegram, WhatsApp.
- Telegram-бот или CRM endpoint для заявок.
- Реквизиты ИП и проверенные юридические тексты.
- Страницу прайса.
- Каталог новой/б/у техники и сценарий предзаказа.
