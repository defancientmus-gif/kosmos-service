# КОсмос сервис — карта памяти

Рабочий репозиторий для проектов сервиса по ремонту телефонов.

## Контекст бизнеса

- Работаем с физлицами и корпоративными клиентами.
- Главный принцип: быстрый ответ, прозрачный ремонт, без сюрпризов.
- Тон коммуникации: живой, конкретный, без канцелярита.

## Структура

- `texts/README.md` — карта памяти и постоянный контекст.
- `texts/NEXT.md` — текущая задача, итоги прошлой сессии и следующий шаг.
- `projects/tg-bot/` — бот для приёма заявок.
- `projects/crm/` — CRM или внутренняя админка, если понадобится.

## Решения

- API ключи храним только в `.env`.
- Перед деплоем проверяем локально.
- Коммитим только нужные файлы.
- Ошибки логируем, клиенту не показываем стектрейсы.
