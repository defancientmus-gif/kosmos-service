# Космос Сервис — карта памяти

Рабочий репозиторий для проектов сервиса по ремонту телефонов Космос Сервис.

## Контекст бизнеса

- Работаем с физлицами и корпоративными клиентами.
- Главный принцип: быстрый ответ, прозрачный ремонт, без сюрпризов.
- Тон коммуникации: живой, конкретный, без канцелярита.
- Главная цель: оптимизировать и улучшить среду формирования клиентской базы и прибыли сервиса.
- Сайт и цифровые инструменты — фундамент, ниже которого сервис не спускается даже в плохие времена.
- Развиваем цифровой клон сервиса: ремонт, новая и б/у техника, ПО, корпоративные задачи, современные каналы связи.
- Глобальная миссия всех проектов: минимум шума. Человек должен интуитивно понимать, куда нажимать, а лучше вообще не нажимать — чтобы система сама доводила до следующего шага.

## Структура

- `texts/README.md` — карта памяти и постоянный контекст.
- `texts/NEXT.md` — текущая задача, итоги прошлой сессии и следующий шаг.
- `texts/SITE_STRATEGY.md` — философия и стратегия сайта.
- `texts/CRM_AGENT_STRATEGY.md` — стратегия персонального ИИ-агента и CRM.
- `projects/site/` — личный сайт сервиса.
- `projects/tg-bot/` — бот для приёма заявок.
- `projects/crm/` — CRM или внутренняя админка, если понадобится.

## Решения

- API ключи храним только в `.env`.
- Перед деплоем проверяем локально.
- Коммитим только нужные файлы.
- Ошибки логируем, клиенту не показываем стектрейсы.
- Спорные юридические вопросы обсуждаем с живым бухгалтером.
- Сайт не обещает финальную цену ремонта до диагностики.
- Предзаказ техники сначала оформляем как заявку на подбор, пока не проверены поставщик, документы и налоговые нюансы.
- Для сайта используем реальные материалы сервиса: фото/видео мастерской, актуальные бренд-файлы и фирменный цвет морской волны.
- Визуальный логотип и wordmark — `KOSMOS`; рабочее название проекта — `Космос Сервис`.
