# FNS_EXPORT_CHECKLIST — выгрузка документов из ЛК ФНС

## Статус

Прямое управление ЛК ФНС через in-app browser после сброса контроллера заблокировано политикой безопасности браузера Codex.

Рабочий режим:

- владелец входит в ЛК ФНС сам;
- владелец скачивает файлы по этому чеклисту;
- агент раскладывает скачанные файлы в цифровой сейф, ведёт реестр, сроки, вопросы бухгалтеру и напоминания;
- заявления, платежи, подпись КЭП и отправка данных выполняются только после отдельного подтверждения владельца.

## Что скачать в первую очередь

### 1. Выписка ЕГРИП

Где:

- `Жизненные ситуации → Получить выписку из ЕГРИП`
- после готовности: `Обращения`

Что сохранить:

- электронную выписку;
- файл подписи / контейнер подписи, если ФНС отдаёт его отдельно;
- дату запроса и дату получения.

Зачем:

- банк;
- контрагенты;
- сайт;
- бухгалтер;
- внутренний юридический профиль сервиса.

### 2. ЕНС — баланс, обязательства, операции

Где:

- `Главная → Детали`
- `Единый налоговый счет → Мой баланс`
- `Единый налоговый счет → Платежи. Операции`
- `Единый налоговый счет → Заявления`

Что скачать:

- выгрузку `Платежи. Операции`;
- данные `Мой баланс`;
- документы / заявления по ЕНС, если есть;
- сведения о задолженности / переплате.

Зачем:

- календарь налоговых обязательств;
- сверка оплат;
- контроль переплаты;
- вопросы бухгалтеру.

### 3. Патент / ПСН

Что скачать:

- патент на 2026 год;
- все уведомления или решения по патенту;
- документы по уменьшению ПСН, если есть;
- историю начисления / уменьшения патента.

Что уже видно:

- патент №`9102250005593` от `02.12.2025`;
- операция по ПСН на `7 518,00 ₽`.

Зачем:

- подтвердить законность режима;
- понимать сроки оплаты;
- сверить уменьшение налога;
- дать бухгалтеру документальную базу.

### 4. УСН / режимы налогообложения

Что скачать или зафиксировать:

- сведения о применяемых налоговых режимах;
- уведомления по УСН;
- историю поданных уведомлений;
- документы, если ФНС показывает переходы / подтверждения.

Зачем:

- корректные юридические формулировки сайта;
- понимание, какие доходы и расходы учитывать;
- вопросы бухгалтеру по спорным видам деятельности.

### 5. Страховые взносы

Где:

- `Услуги. Сервисы → Страховые взносы`
- блок `Ближайшие события`

Что скачать / зафиксировать:

- обязательства по фиксированным взносам;
- сроки;
- суммы;
- документы / уведомления;
- события по месяцам.

Зачем:

- напоминания;
- календарь платежей;
- контроль просрочек.

### 6. Уведомления, требования, обращения

Что скачать:

- все входящие уведомления ФНС;
- требования;
- ответы на обращения;
- историю заявлений;
- статусы запросов.

Зачем:

- не пропустить важное;
- хранить переписку с ФНС;
- быстро готовить вопросы бухгалтеру.

### 7. КЭП

Где:

- `Услуги. Сервисы → Получение КЭП`

Что зафиксировать:

- есть ли действующая КЭП;
- срок действия сертификата;
- где физически хранится носитель / токен;
- кто знает PIN;
- какие сервисы используют эту подпись.

Важно:

- PIN, пароль и носитель КЭП не хранить в репозитории и не передавать агенту;
- в цифровом сейфе хранить только метаданные и сроки.

### 8. ККТ / касса / фискальные данные

Где:

- `Контрольно-кассовая техника`
- `Список касс`
- `Фискальные данные`

Что скачать / зафиксировать:

- список касс;
- регистрационные карточки;
- параметры ОФД;
- сроки ФН;
- статусы касс;
- фискальные отчёты, если доступны.

Зачем:

- контроль законности продаж;
- напоминания о ФН / ОФД;
- связь с бухгалтерией и CRM.

## Как передать файлы агенту

После скачивания сложить файлы в одну папку, например:

`/Users/defancient/Documents/Космос Сервис/_inbox/fns/`

Потом агент:

1. разберёт файлы по категориям;
2. создаст реестр документов;
3. выпишет сроки и платежи;
4. выделит спорные вопросы бухгалтеру;
5. обновит `texts/DOCUMENTS_FINANCE_HUB.md` и текущую задачу.

## Не делать без отдельного подтверждения

- не отправлять заявления;
- не подписывать КЭП;
- не формировать платежи;
- не менять налоговый режим;
- не подавать согласия на раскрытие налоговой тайны;
- не менять данные ИП;
- не регистрировать / не снимать ККТ.
