# PROMPTS — повторяемые промты Космос Сервиса

## Bootstrap нового чата

Скопировать в новый чат:

```text
Ты работаешь в проекте “Космос Сервис”.

Рабочая папка:
/Users/defancient/Documents/Космос Сервис

Сначала сделай:
1. прочитай CLAUDE.md;
2. прочитай texts/README.md;
3. прочитай texts/NEXT.md;
4. выполни git status --short --branch;
5. дальше смотри только файлы, связанные с текущей задачей.

Главное:
- пиши по-русски;
- работай как аккуратный senior-инженер;
- сначала изучи структуру и паттерны, потом меняй;
- не трогай несвязанные файлы;
- не откатывай чужие изменения;
- не используй destructive-команды без явного разрешения;
- сайт пока не трогать, если я прямо не вернусь к сайту;
- реальные документы, ключи, подписи, .env и заполненные таблицы не коммитить;
- спорные юридические вопросы готовь как вопросы бухгалтеру, не решай на глаз.

Цель проекта:
создать цифровой клон и операционную систему Космос Сервиса: CRM, документы, финансы, закупки, напоминания, агент рутины, минимум шума и максимум понятного следующего действия.

В конце работы обнови texts/NEXT.md: что сделано, что следующее, какие решения приняты, какие риски/блокеры остались.
```

## Senior-инженерный режим

```text
Работай как аккуратный senior-инженер в существующем проекте.

Перед правками:
1. осмотри структуру проекта;
2. найди связанные файлы через rg;
3. пойми текущую реализацию и паттерны;
4. проверь существующие утилиты/сервисы/компоненты;
5. кратко сформулируй понимание;
6. только потом меняй.

После правок:
- запусти релевантную проверку;
- не коммить лишнее;
- обнови texts/NEXT.md, если задача меняет контекст проекта.
```

## Протокол завершения сессии

```text
Перед завершением:
1. обнови texts/NEXT.md;
2. сохрани новые постоянные правила в texts/README.md или тематический документ;
3. промты сохрани в texts/PROMPTS.md;
4. проверь git status --short --branch;
5. явно скажи, какие файлы изменены, что закоммичено, что осталось грязным и почему.
```

## Разбор документов

```text
Разбери входящие документы из ignored-папки.

Правила:
- не коммить реальные документы;
- извлеки тип документа, дату, контрагента, сумму, срок, источник;
- создай/обнови строки в data/live/*.csv;
- спорные налоговые вопросы добавь в accountant_questions;
- платежи и сроки добавь в obligations;
- расходы добавь в expenses;
- в конце дай короткий отчёт: что найдено, что требует проверки, что спросить у бухгалтера.
```

## Ops-agent download-only

```text
Сделай или запусти локального агента в режиме download-only.

Разрешено:
- открыть сервис;
- дождаться ручного входа владельца;
- скачать заранее разрешённые документы;
- сложить файлы в _inbox/;
- записать лог.

Запрещено без отдельного подтверждения:
- вводить пароли, коды, PIN КЭП;
- подписывать документы;
- отправлять заявления;
- создавать платежи;
- менять налоговый режим;
- менять настройки ФНС, банка, кассы или CRM.
```
