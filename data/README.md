# Data — реестры и шаблоны

## Назначение

Здесь лежат шаблоны таблиц для цифрового сейфа и будущей CRM-операционки.

## Папки

- `templates/` — пустые шаблоны, их можно коммитить.
- `live/` — реальные заполненные таблицы, папка игнорируется git.

## Как работать

1. Скопировать нужный шаблон из `data/templates/` в `data/live/`.
2. Заполнять `data/live/` реальными документами, платежами и расходами.
3. Не коммитить `data/live/`.
4. Когда структура подтвердится, перенести её в SQLite / Supabase / внутреннюю CRM.

Автоматическая подготовка локальных таблиц:

```sh
projects/ops-agent/scripts/kosmos-auto.sh init
```

Команда создаёт недостающие файлы в `data/live/` из шаблонов и не перезаписывает уже заполненные таблицы.

## Шаблоны

- `documents.csv` — склад документов.
- `obligations.csv` — календарь платежей и сроков.
- `expenses.csv` — расходы.
- `suppliers.csv` — поставщики.
- `accountant_questions.csv` — вопросы бухгалтеру.
- `action_log.csv` — журнал действий агента.
- `download_tasks.csv` — задачи на выгрузку из ФНС, банка, LiveSklad и поставщиков.
- `owner_profile.csv` — шаблон локального профиля владельца без реальных данных.
- `business_identity.csv` — шаблон локальной карточки ИП/бизнеса без реальных данных.
- `vault_collection_checklist.csv` — чеклист сбора базового пакета документов.
